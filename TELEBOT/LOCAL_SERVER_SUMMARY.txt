🐛 حل المشاكل الشائعة | Troubleshooting
───────────────────────────────────────────────────────────────────────────

❌ "Address already in use"
   → غيّر PORT في .env إلى 8001
   → أو: netstat -ano | findstr :8000 ثم taskkill /PID <PID> /F

❌ "Module not found"
   → pip install -r requirements.txt

❌ ".env file not found"
   → copy .env.example .env

❌ "Bot not responding"
   → تأكد من TELEGRAM_API_KEY الصحيح
   → تحقق من السجلات: bot.log
