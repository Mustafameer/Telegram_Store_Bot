# 📚 دليل الأوامس والميزات

## 🎮 أوامس المستخدم العادي

### `/start`
**الوصف:** بدء البوت والحصول على القائمة الرئيسية  
**المثال:** `/start`  
**الرد:** عرض الخيارات الرئيسية

---

### `/request`
**الوصف:** طلب شحن جديد  
**المثال:** `/request`  
**العملية:**
1. اختر شركة الشحن (Asiacell, Zain, Korek...)
2. أدخل رقم الهاتف
3. اختر قيمة الشحن
4. أكمّل الدفع

---

### `/account`
**الوصف:** عرض حسابك وميزانيتك  
**المثال:** `/account`  
**المعلومات:**
- الرصيد الحالي
- عدد العمليات
- آخر النشاطات

---

### `/history`
**الوصف:** عرض سجل العمليات السابقة  
**المثال:** `/history`  
**المعلومات:**
- تاريخ العملية
- الشركة والمبلغ
- حالة العملية

---

## 🔑 أوامس المالك/المسؤول

### `/admin`
**الوصف:** دخول لوحة تحكم المسؤول  
**المثال:** `/admin`  
**الخيارات:**
- إدارة الأسعار
- عرض التقارير
- إدارة المستخدمين

---

### `/profit`
**الوصف:** عرض الأرباح الحالية  
**المثال:** `/profit`  
**المعلومات:**
- أرباح كل شركة
- الإجمالي اليومي/الشهري

---

### `/users`
**الوصف:** عرض قائمة المستخدمين  
**المثال:** `/users`  
**المعلومات:**
- عدد المستخدمين الكلي
- المستخدمين النشطين
- الإحصائيات

---

### `/stats`
**الوصف:** إحصائيات مفصلة  
**المثال:** `/stats`  
**يتضمن:**
- عدد الطلبات
- المبالغ المتحصلة
- أفضل الشركات

## 💾 قواعد البيانات الرئيسية

### جدول `users`
| الحقل | النوع | الوصف |
|------|------|-------|
| id | INT | معرّف فريد |
| from_id | INT | معرّف Telegram |
| username | VARCHAR | اسم المستخدم |
| first_name | VARCHAR | الاسم الأول |
| last_name | VARCHAR | الاسم الأخير |
| balance | DECIMAL | الرصيد الحالي |
| state | VARCHAR | الحالة الحالية |
| report | JSON | التقرير |

### جدول `bot`
| الحقل | النوع | الوصف |
|------|------|-------|
| key | VARCHAR | مفتاح الإعداد |
| value | TEXT | القيمة |

**المفاتيح المهمة:**
- `owners`: معرفات المالكين
- `admins`: معرفات المسؤولين
- `profit`: الأرباح الحالية
- `status`: حالة البوت

### جدول `states`
| الحقل | النوع | الوصف |
|------|------|-------|
| id | INT | معرّف المستخدم |
| state | VARCHAR | الحالة الحالية |
| param | JSON | البارامترات الإضافية |

## 🔄 تدفق العمليات

### شحن هاتف عادي
```
1. /start أو اختر "شحن"
2. اختر الشركة
3. أدخل رقم الهاتف
4. اختر المبلغ
5. اختر طريقة الدفع
6. تأكيد العملية
7. ✅ تم الشحن بنجاح
```

### طلب رصيد جديد
```
1. /request
2. ملء نموذج الطلب
3. انتظار الموافقة
4. إكمال الدفع
5. ✅ تم تحديث الرصيد
```

### عملية الإدارة
```
1. /admin
2. اختر المهمة (أسعار، مستخدمين...)
3. عدّل الإعدادات
4. ✅ تم الحفظ
```

## 📊 الحالات (States)

| الحالة | الوصف |
|------|-------|
| `null` | لم يبدأ بعد |
| `menu` | في القائمة الرئيسية |
| `choosing_company` | اختيار الشركة |
| `choosing_amount` | اختيار المبلغ |
| `entering_number` | إدخال الرقم |
| `confirming` | تأكيد العملية |
| `processing` | جاري المعالجة |
| `completed` | اكتملت العملية |
| `admin_menu` | قائمة الإدارة |

```json
  "zain": 75,
  "korek": 100,
  "iraqsell": 60,
  "alkafil": 80
}
```

```json
[5420647695, 123456789]
```

### الشركات المتاحة
في ملف `numbers.json`:
```json
{
  "asiacell": {
    "name": "Asiacell",
    "prefix": 750,
    "charges": [500, 1000, 5000]
  }
}
```

## 📞 رموز الخطأ

| الكود | الوصف | الحل |
|------|-------|------|
| 001 | فشل الاتصال بقاعدة البيانات | تحقق من MySQL |

## 📈 نصائح للتحسين

### الأداء
- ⚡ استخدم PHP 8.0+
