5️⃣  🐛 استكشاف الأخطاء | Troubleshooting
═══════════════════════════════════════════════════════════════════════

المشاكل الشائعة:
──────────────────────────────────────────────────────────────────────

  ❌ "Address already in use"
     → غيّر PORT في .env إلى 8001
     → أو: netstat -ano | findstr :8000

  ❌ "Module not found"
     → pip install -r requirements.txt

  ❌ ".env file not found"
     → copy .env.example .env

  ❌ "Bot not responding"
     → تحقق من TELEGRAM_API_KEY
     → اطّلع على bot.log

  ❌ "Connection refused"
     → تأكد من أن السرفر يعمل
     → تحقق من الـ IP والـ PORT

➜ اقرأ: SERVER_SETUP.md للحل المفصل
