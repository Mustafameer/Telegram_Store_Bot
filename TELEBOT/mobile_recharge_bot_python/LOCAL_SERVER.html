Mobile Recharge Bot - Local Server Setup

المعلومة القيمة
🌐 عنوان IP 192.168.0.108
🔌 المنفذ 8000
📍 رابط الـ Webhook http://192.168.0.108:8000/webhook

⚙️ البيئة Local Development

⚡ البدء السريع

1 فتح سطر الأوامر (Command Prompt)

افتح نافذة Command Prompt أو PowerShell

2 الذهاب إلى مجلد المشروع
cd c:\Users\Hp\Desktop\TELEBOT\mobile_recharge_bot_python
3 تثبيت المتطلبات (المرة الأولى فقط)
pip install -r requirements.txt
4 تشغيل السرفر
python start_server.py

أو انقر على ملف start.bat

✅ إذا رأيت "Starting bot on 192.168.0.108:8000" فالسرفر يعمل بنجاح!

✅ اختبار السرفر

اختبر الـ Status
curl http://192.168.0.108:8000/status

النتيجة المتوقعة:

{"status": "running"}
اختبر معلومات الـ Webhook
curl http://192.168.0.108:8000/get_webhook_info
اختبر البوت على Telegram

افتح Telegram وابحث عن البوت الخاص بك

أرسل الرسالة: /start

يجب أن تتلقى رسالة ترحيب

🔗 نقاط النهاية (API Endpoints)

الطلب الوصف الأمثلة
POST /webhook استقبال التحديثات من Telegram تحديثات البوت
GET /status حالة السرفر http://192.168.0.108:8000/status
GET /test اختبار الاتصال بـ Telegram http://192.168.0.108:8000/test
GET /get_webhook_info معلومات الـ Webhook http://192.168.0.108:8000/get_webhook_info

🐛 استكشاف الأخطاء

❌ المشكلة: "Address already in use"

السبب: البوت يعمل بالفعل على نفس المنفذ

الحل: غيّر PORT في ملف .env إلى 8001

❌ المشكلة: "Module not found"

السبب: المتطلبات لم تُثبّت

pip install -r requirements.txt
⚠️ تلميح: اطلع على ملف bot.log لتفاصيل أكثر عن الأخطاء

⚙️ الإعدادات

جميع الإعدادات موجودة في ملف .env

الإعدادات الرئيسية:
الإعداد القيمة الحالية الوصف
HOST 192.168.0.108 عنوان IP
PORT 8000 المنفذ
DEBUG True وضع التطوير
LOG_LEVEL DEBUG مستوى التسجيل
DATABASE_URL sqlite:///bot_data.db قاعدة البيانات

الملفات الرئيسية:
  • start_server.py - نقطة الدخول للسرفر
  • start.bat - ملف تشغيل سريع
  • webhook.py - تطبيق Flask
  • config.py - الإعدادات
  • database.py - قاعدة البيانات
  • handlers.py - معالجات الرسائل
  • .env - متغيرات البيئة
