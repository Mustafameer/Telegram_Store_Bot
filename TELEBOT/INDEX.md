### 📂 ملفات المشروع الرئيسية

#### **مجلد المشروع:**
```
mobilerechargev2 2/mobilerechargev2/
```

| الملف | الوصف |
|------|-------|
| `config.php` | الإعدادات والمفاتيح (⚠️ عدّل هنا!) |
| `xindex.php` | معالج Webhook الرئيسي |
| `cronjob.php` | المهام المجدولة |
| `mr.sql` | قاعدة البيانات |
| `numbers.json` | قائمة الشركات |

---

#### **مجلد Control:**
```
Control/main.class.php
```
- الفئة الرئيسية للبوت
- جميع الوظائف الأساسية

---

#### **مجلد Plugins:**
```
Plugins/User/      → أوامس المستخدم
Plugins/Owner/     → أوامس المالك
Plugins/Admin/     → أوامس المسؤول
```

#### **مجلد Languages:**
