## 📱 كيفية تشغيل التطبيق

### الطريقة 1: تسجيل دخول بـ ID المسؤول
**اُدخل المعرف التالي في شاشة تسجيل الدخول:**
```
1041977029
```

هذا هو معرّف Seller الذي تم إدراجه في قاعدة البيانات السحابية.

### الطريقة 2: إضافة seller جديد من لوحة التحكم
1. سجّل دخول بـ أي معرف (سيصبح admin تلقائياً)
2. من لوحة التحكم → انقر "+" لإضافة متجر جديد
3. أدخل بيانات المتجر ← سيتم حفظه مباشرة في PostgreSQL السحابية

## 🔄 هيكل تدفق البيانات

```
Flutter App
    ↓
DatabaseHelper (واجهة موحدة)
    ↓
DatabaseHelperCloud (cloud operations)
    ↓
PostgresService (اتصال مباشر PostgreSQL)
    ↓
Railway PostgreSQL Cloud
```

### معايير البيانات:
- **Host**: switchback.proxy.rlwy.net
- **Port**: 20266
- **Database**: railway
- **User**: postgres
- **SSL**: مفعّل ✓

## 📝 النقاط المهمة

### ✅ البيانات الآن من السحابة:
- ✓ عند فتح التطبيق، يتم تحميل المتاجر من PostgreSQL مباشرة
- ✓ عند إضافة منتج، يتم حفظه في السحابة فوراً
- ✓ عند تعديل متجر، يتم التحديث في السحابة

### ⚠️ لا توجد بيانات hardcoded:
- لا توجد بيانات افتراضية في الكود
- جميع البيانات تأتي من قاعدة البيانات السحابية
- عند حذف البيانات من قاعدة البيانات، ستختفي من التطبيق
